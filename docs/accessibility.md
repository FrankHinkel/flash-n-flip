# Accessibility baseline

Flash & Flip targets WCAG 2.2 AA for Web and equivalent native behavior.

- Core flows support keyboard, VoiceOver, and TalkBack.
- Gestures have visible alternatives.
- Ratings and status do not rely on color alone.
- Text scaling, browser zoom, dark mode, and reduced motion are supported.
- Images require alt text or an explicit decorative flag.
- Charts include textual summaries.
- Destructive actions name their target and require confirmation.

Automated checks complement, but never replace, tests with real assistive
technology and representative users.

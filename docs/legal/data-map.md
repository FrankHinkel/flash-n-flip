# Datenlandkarte – lokaler Generation-2-Zielbetrieb

Stand: 9. September 2026. Fuer den Offline-Lernbetrieb massgeblich bleiben die
lokalen Stores. Die Web/PWA ist unter `/app` aktiv; Release 0.5.171 stellt die
private iCloud-Replikation fuer eine ausdrueckliche Zwei-Geraete-Abnahme bereit.

Im Apple-V1-Build nicht aktiv: Registrierung, Flash-n-Flip-Konto,
Gerätekopplung, WebRTC, Rendezvous, STUN, Passwortwiederherstellung, Admin-App,
Community-Veröffentlichung/-Moderation, private VPS-Uploads, serverseitige
Imports, PostgreSQL als Produktdienst, Analytik, Werbung, Zahlungen und
TURN-Relay.

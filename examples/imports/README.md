# Beispielimporte

## Allgemeinwissen Starter

`allgemeinwissen-starter.csv` enthält 24 deutschsprachige Karten aus
Geografie, Naturwissenschaften, Mathematik, Sprache, Kultur und Geschichte.

Import in der Webanwendung:

1. **Meine Lernsets** öffnen.
2. **Importieren** wählen.
3. Als Titel `Allgemeinwissen Starter` eingeben.
4. Das Format **CSV (Vorderseite, Rückseite, Tags)** auswählen.
5. `allgemeinwissen-starter.csv` hochladen.
6. **Import starten** wählen.

Die Datei enthält ausschließlich UTF-8-Text und keine aktiven HTML-,
JavaScript- oder Anki-Add-on-Inhalte.

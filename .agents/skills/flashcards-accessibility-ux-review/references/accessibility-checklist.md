# Accessibility checklist

- Web core flows pass keyboard-only operation and automated axe checks.
- Mobile core flows expose meaningful accessibility labels, roles, values, hints, and state.
- Focus moves to the first invalid field and returns after closing dialogs.
- Rating controls explain meaning and next interval without relying on color.
- Charts provide a textual summary.
- Images require alt text or an explicit decorative flag.
- Audio controls expose play, pause, position, and transcript or label.
- Dynamic Type and browser zoom do not hide primary actions.
- Animations honor reduced-motion settings.
- Destructive actions name the affected deck, account, or revision.
